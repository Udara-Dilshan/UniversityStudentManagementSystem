## ✨ Overview

**UniVerse** is a responsive University Student Management System prototype created with **Figma Make** and exported as a modern frontend application.

The concept brings core academic workflows into one centralized experience, helping students and lecturers manage courses, assignments, grades, attendance, timetables, announcements, communication, and personal settings through a polished SaaS-style interface.

> **Current stage:** UI / functional prototype  
> **Next direction:** evolve the prototype into a fully connected application with real authentication, APIs, persistent data, and role-based workflows.

---

## 🎯 Product Vision

UniVerse is designed around a simple idea:

> **One connected workspace for the everyday academic journey.**

The interface focuses on:

- 📊 Clear academic visibility
- ⚡ Fast access to important actions
- 🧭 Consistent navigation
- 📱 Responsive layouts across devices
- 🌙 A premium dark visual system
- 👥 Student and lecturer-oriented workflows
